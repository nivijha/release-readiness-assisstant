# Release Communication and Readiness Brief Assistant

## Tech Stack
- React
- Vite
- Tailwind CSS
- Node.js
- Express
- MongoDB
- Mongoose
- Gemini/OpenRouter (future AI integration)

## Architecture

Frontend → Express REST API → Services → MongoDB

## Running Locally

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```

Environment variables are required. See `server/.env.example` for configuration.
